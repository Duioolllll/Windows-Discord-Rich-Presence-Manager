# Changelog

## 0.3.0

- Track running desktop applications, preferring the active window and keeping a running selection when focus moves to an excluded app.
- Request the detected app name and supported app icon in Discord; allow custom display names and image references.
- Temporarily disable browser and website detection, including the Native Messaging server.
- Add an application and tray icon, retry interrupted process monitors, and clear activity when idle status is unavailable.
- Windows execution and Discord rendering remain unverified.

## 0.2.0

- Add first-run English/Korean selection and Discord connection setup; language remains configurable in Settings.


## 0.1.0

- Initial development preview of foreground detection, local Discord IPC, browser messaging, rules and desktop settings.
- Windows operation, packaging and end-to-end behavior remain unverified.
